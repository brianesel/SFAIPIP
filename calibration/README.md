# Calibration

Before trusting scores:
1. Pick 2 orgs the team knows well (one healthy, one messy).
2. Ask 2 senior people for a gut score 0–100 per pillar, independently.
3. Run the assessment + `score.py`.
4. Adjust check weights, `zero_at`/`full_at`, and profile targets until each pillar is within ±10 of the expert average.
5. Record changes and reasons here, with date.

`example-results.json` = sample input for testing the scorer.
