# Definition of Ready (G3)

A ticket enters a sprint only when every box is ticked.

- [ ] Linked to REQ-nnn (or CR-nnn); no duplicate found in tracker search
- [ ] Acceptance criteria testable (Given/When/Then), incl. negative case
- [ ] Technical spec names exact metadata (objects, fields, flows, classes, permission sets)
- [ ] Pattern stated per pattern register (current or target + ADR)
- [ ] Sharing / permissions defined (who can see/run it)
- [ ] Test approach: unit tier and/or integration tier (bulk 251+, runAs if access matters)
- [ ] Hard-gate risk named or "none"; pillar impact noted
- [ ] Dependencies linked (blocks / blocked by) and not blocking now
- [ ] Migration items in scope (M-nn) fit the boy scout budget
- [ ] Estimate agreed; fits one sprint (else split)
- [ ] No open question tagged [low]/[dunno]
